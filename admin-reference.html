Admin Panel Reference

A plain-English explanation of every button, checkbox, and dropdown on every admin page — for when you want to know exactly what something does before you click it. If you're brand new to the site, start with the Getting Started Guide instead; come back here as a lookup once you're comfortable with the basics.

Dashboard

The first page you see after logging in — a read-only snapshot plus shortcuts to common tasks. Nothing here can be "broken" by clicking around.

Stat cards (Sales this month, Orders this month, etc.)
Just numbers — no action. "Prints fulfilled" is clickable and jumps to Orders.
New gallery / New folder / Find a photo / Homepage background (Quick actions)
Shortcuts straight to those pages, skipping the nav menu.
View all messages →
Jumps to the full Messages page.

Orders

Every sale, newest first. Click anywhere on a row to expand it and see the full breakdown.

Export contacts (CSV)
Downloads every customer's name, phone, and email as a spreadsheet file.
Find a photo (search box)
Type a filename, title, or bib number to filter the list down to just orders containing that photo.
⬇ Download (next to a photo)
Grabs a copy of that specific purchased photo for yourself — no need to hunt down the original file.
Download all as ZIP
Downloads every digital photo in that order at once, zipped together.
Copy customer's download-all link
Copies the exact link the customer got in their email — paste it into a message to resend it if they lost it.
Reset download limit
Refills a customer's download link back to full uses without changing the link itself — use if they've hit their download cap and need another try.
Mark prints fulfilled & email customer
Records the ship date, carrier, tracking number, and print lab (all optional), then automatically emails the customer a shipping confirmation.
Resend confirmation email
Re-sends the exact same order-confirmation/download-links email. Grayed out if the order has no email on file.
Delete order
Permanently removes an order — use for test or junk orders only. Cannot be undone.

Messages

Every submission from your site's Contact form, kept here as a permanent backup even if the notification email is missed.

Mark as read
Clears a message's "unread" highlight and removes it from the red counter badge.
Delete
Permanently removes a message.

Homepage & Menu

Controls the homepage's background photo and the sidebar menu shown on every page of your site.

Upload (Homepage background)
Adds one or more photos as the homepage's background. More than one photo means a random one shows on each visit.
Add from an existing gallery
Search photos you've already uploaded elsewhere instead of uploading a duplicate copy just for the homepage.
+ Add to homepage
Adds that search result photo to the homepage background rotation.
Delete (under a background photo)
Removes that photo from the homepage background rotation.
↑ / ↓ (next to a menu item)
Moves that item up or down in the sidebar menu order.
Delete (next to a menu item)
Removes that link from the sidebar menu entirely (doesn't delete the gallery/page/folder itself).
Add (gallery/page/folder link)
Adds a menu link pointing at a gallery, page, or folder you pick from the dropdown. Leave "Label" blank to use its title automatically.
Add (custom link)
Adds any link you want — an outside website, a specific gallery URL, anything. Use a full "https://" address for outside links, or a path like "/galleries" for a page on your own site.

Galleries

The master list of every gallery, grouped by folder.

+ New gallery
Opens the form to create a new gallery — give it a title, description, and (optionally) a folder.
Order galleries by
Newest first, earliest first, or "Set manually" to drag galleries into your own custom order within this admin list and on the public Galleries page.
Order folders by (this page only)
Changes only how folder sections are arranged in this admin list — doesn't affect what visitors see.
Order folders on the public Races & Events page by
Controls the order visitors actually see. "Set manually" reveals a drag-to-reorder list further down, mixing folders and standalone galleries together in any order you like.
⠿ (drag handle)
Click and drag this handle to reorder a row, when a manual sort mode is active.
Manage
Opens that gallery's full edit page (uploading photos, settings, etc.).
Copy link
Copies that gallery's public shareable URL to your clipboard.
Folder heading (click to expand/collapse)
Collapses or expands that folder's list of galleries — just for your own browsing convenience here.

Inside a gallery (the edit page)

The busiest page in the whole admin panel — this is where you upload and organize photos for one specific gallery.

Copy link (top of page)
Copies this gallery's public URL.
+ Create backdoor gallery
One-click setup of a private, hidden "feeder" gallery whose photos automatically also appear on this public gallery — handy for uploading through the desktop app to a private gallery that feeds a public one. Backdoor galleries default to free downloads with no watermark (they're for handing off clean working files, not browsing proofs); the public gallery they feed keeps showing watermarked previews regardless, so this never affects what customers see.
Save settings
Saves everything in the Settings section: title, description, page content, folder assignment, photo sort order, privacy/password, download mode, prints toggle, cross-listing, logo, watermark, and auto-delete date.
Regenerate previews with current watermark + logo
Re-renders every preview photo in the gallery using whatever watermark/logo settings are currently saved — only needed after changing those settings on a gallery that already has photos uploaded.
Delete gallery
Permanently deletes the gallery and every photo in it. Cannot be undone.
Download ZIP (Bulk resized download)
Downloads every photo currently in the gallery as one ZIP file, at the size you choose (or full size), with or without the event logo.
Add folder (within a gallery)
Creates a sub-folder inside this gallery — e.g. "Start Line," "Finish Line" — to group photos.
↑ / ↓ (next to a folder)
Reorders that sub-folder, when "Set manually" is chosen for folder order in Settings.
Delete (next to a folder)
Removes the folder; its photos move back to "Unsorted" rather than being deleted.
Upload
Uploads the selected photos into this gallery (optionally straight into a specific folder), handling duplicate filenames however you choose from the dropdown.
Cancel remaining (during an upload)
Stops an in-progress upload batch partway through — anything already processed stays uploaded.
Upload CSV (Add names from a CSV)
Matches a two-column bib-number/name spreadsheet against already-tagged photos, adding the participant's name as a searchable tag.
Gallery drop zone (Move to another gallery)
Drag a photo (or a selected group) onto one of these to move it into a different gallery entirely.
Select all / Clear selection / Delete selected
Bulk-select every photo (or clear the selection), then permanently delete everything selected in one action.
Cover photo (checkbox on a thumbnail)
Marks that specific photo as the one always shown on this gallery's card on the public Galleries/folder pages. Leave none checked to let the site rotate a random photo instead.
Folder dropdown (on a thumbnail)
Moves that one photo into a different folder within the gallery.
↑ / ↓ (on a thumbnail)
Nudges that photo's position, when manual photo ordering is turned on in Settings.
Save tags
Updates that photo's bib-number/name tags — the same field bib-number search matches against.
Delete (on a thumbnail)
Permanently deletes that one photo.

Folders

Groups of galleries — typically one folder per event.

Add (new folder)
Creates a folder, optionally nested inside another one, optionally private/password-protected, and optionally pre-loaded with a whole list of galleries typed in at once (one name per line) — with the option to also auto-create a matching "backdoor" gallery for each.
Fix download settings for all backdoor galleries
A one-click cleanup that switches every cross-listed "backdoor" gallery site-wide to free full-gallery downloads with prints off. Doesn't touch the watermark setting — backdoor galleries default to unwatermarked, and that no longer affects the public gallery they feed.
View ↗
Opens that folder's public page in a new tab.
Copy link
Copies that folder's public shareable URL.
Edit settings (expand)
Reveals the full settings form for that folder — parent folder, privacy/password, page content, and auto-delete date.
Save (folder settings)
Saves whatever you changed in that folder's settings form.
Remove password
Clears the folder's password while leaving it hidden from public listings — a direct link still works, just without a password prompt.
Upload / Replace hero image
Sets the image shown at the top of the folder's public page and used as its social-media preview image.
Remove hero image
Removes the folder's hero image.
Delete folder
Deletes the folder itself — its galleries are NOT deleted, they just become uncategorized. Any sub-folders move up a level.

Find a Photo

Search by filename across the whole site (or one folder) to track down a specific photo fast.

Search
Runs the filename search using the text and folder you've selected.
⬇ Download all as ZIP
Downloads every matching result at once.
Include event logo (checkbox)
If that result's gallery has a logo assigned, downloads the with-logo version instead of the clean one.
⬇ Download (on a result)
Downloads that one specific photo.
Gallery title link (under a result)
Jumps straight to that photo's spot in its gallery's edit page.

Galleries Background

Same idea as the homepage background, but for the public Galleries listing page instead.

Upload
Adds one or more photos to the Galleries page's background slideshow.
Add from an existing gallery / + Add
Search and reuse a photo already uploaded elsewhere instead of uploading a fresh copy.
Delete (under a background photo)
Removes that photo from the rotation.

Pages

Standalone custom pages — About, FAQ, Contact, or anything else — built from stackable content blocks.

+ New page
Creates a new blank page, ready to add content blocks to.
Edit
Opens that page's block editor.
Save title
Updates the page's title (and its URL slug).
⠿ (drag handle on a block)
Drag to move that block anywhere in the page's top-to-bottom order.
↑ / ↓ (on a block)
Nudges a block one position instead of dragging it.
Delete (on a block)
Removes that block from the page permanently.
Edit (expand on a block) / Save changes
Opens and saves that specific block's content — text, button label/link, embed code, or replaces its image/video and caption.
Add text / Add photo / Add video / Add button / Add contact form / Add embed
Appends a new block of that type to the bottom of the page. The contact form block embeds the same form as your site's Contact page; the embed block is for pasting third-party iframe/embed code (like a registration widget).
Delete page
Permanently deletes the whole page and every block on it.

Branding

Your site's identity — name, logo, social links, analytics, return address, and print labs.

Save (Site name)
Updates the name shown at the top of your sidebar on every page.
Upload logo
Sets your site's logo — also automatically becomes your browser-tab favicon.
Remove (Logo)
Removes the logo; the sidebar falls back to showing just the site name.
Add (Social links)
Adds a social media link shown in the sidebar and on gallery pages.
Delete (Social links)
Removes a social link.
Save (Analytics)
Saves your Google Analytics (GA4) and/or Meta Pixel IDs — leave either blank to skip it. Only runs on the public site, never in the admin panel.
Save (Return / from address)
Sets your default shipping "From" address, used on print-fulfilled emails whenever a specific lab isn't picked for that order.
Add lab
Saves a print lab's name, address, and optional logo to reuse when marking orders fulfilled.
Add logo / Replace logo (on a lab)
Uploads or swaps that lab's logo image (shown only in this admin list, not to customers).
Remove logo (on a lab)
Removes that lab's logo image.
Delete (on a lab)
Removes the lab going forward — past orders already fulfilled through it keep showing its address.

Email Status

Checks whether your emails (download links, order confirmations) are actually able to reach real customers.

Send test email
Sends an actual test email to the address you enter — the most reliable way to confirm delivery is working end to end, beyond just checking your account settings above it. If your AWS account is still in "sandbox mode" (shown above this button), the test address needs to already be verified in your AWS console or it'll fail.

Users

Give an assistant or second photographer their own login instead of sharing your main password.

Add user
Creates a new staff login with a username, password, and role. "Staff" can do everything except Branding, Print labs, Email Status, and this Users page; "Full admin" can do everything you can.
Make staff / Make full admin
Switches that user's role between the two access levels.
Delete (on a user)
Removes that user's login entirely — they can no longer sign in.
Set password (Reset password)
Sets a new password for that user — useful if they forget theirs.

Auto-Delete

Review and control every gallery/folder scheduled for automatic future deletion. Off by default, site-wide.

Allow scheduled auto-deletes to actually run (master switch)
The one setting that has to be checked before ANY scheduled deletion happens, no matter what's turned on for an individual gallery or folder. Leave it off to safely set future dates without risk, and review them here first.
Warn me [X days] before a scheduled deletion
How far ahead of a deletion date you get a one-time warning email.
Save (master switch settings)
Saves the master switch and warning-days setting.
Edit (on a scheduled item)
Jumps to that gallery's or folder's own settings page to change or cancel its auto-delete date.
Cancel (on a scheduled item)
Turns off auto-delete for that specific item — it stays on the site indefinitely.
Delete now
Immediately, permanently deletes that item — bypasses both the scheduled date and the master switch entirely. Cannot be undone.

Packages

The pricing bundles customers choose at checkout — a mix of digital downloads and included prints.

Add package
Creates a new package with a name, digital photo count, optional included print sizes/quantities, a price, and optionally restricted to just one gallery.
Edit
Opens that package's edit page to change any of its details, or its "Active" (visible to customers) status.
Save changes (on the edit page)
Saves whatever you changed.
Delete
Permanently removes the package — it stops being offered to new customers; existing orders that already used it are unaffected.

Print Options

À la carte print sizes and shipping options, offered outside of (or on top of) a package.

Add print option
Creates a new individually-purchasable print size with its own price.
Delete (on a print option)
Removes that print size from what customers can buy going forward.
Add shipping option
Creates a shipping speed/price choice customers pick from at checkout whenever their order contains a physical print. Leave the whole list empty to not charge for shipping at all.
Delete (on a shipping option)
Removes that shipping choice.

Download Sizes

The digital download sizes available site-wide, both for individual à la carte purchases and for ZIP-export dropdowns.

Add download size
Creates a new size — set a "Long edge" to cap the longer dimension (works for any orientation), or set an exact Width AND Height together for a fixed bounding box. Leave everything blank for full, unresized resolution. "Available for purchase" controls whether it shows in the customer-facing à la carte picker (uncheck to keep a size ZIP-export-only).
Edit (expand on a size) / Save changes
Opens and saves changes to an existing size's dimensions, price, label, or purchasable status.
Delete (on a size)
Removes that size from being offered going forward.

Logos

A reusable library of sponsor/event logo images that can be composited onto photos.

Add logo
Uploads a new logo image and sets its placement (corner or center), size, margin from the edge, and opacity — PNG with a transparent background works best.
Placement & image (expand) / Save changes
Opens and saves changes to an existing logo's name, placement, or replaces its image file. Changes apply the next time a gallery using it has its previews regenerated.
Delete (on a logo)
Removes the logo — any gallery that was using it falls back to offering no logo option.
