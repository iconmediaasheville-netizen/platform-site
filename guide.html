Getting Started: Running Your Photo Site

A plain-English walkthrough for photographers using this platform to sell race and event photos. No technical background needed — if you can use email, you can run this site.

What this site does for you

Customers come to your site, find their own photos in a race or event gallery — usually by searching their bib number — and buy digital downloads or prints, all without you lifting a finger. You upload the photos once; the site handles bib-number matching, watermarking, checkout, and even follow-up emails automatically. Your job is uploading photos, organizing them by event, and occasionally checking in on orders.

Logging in

Your site has an admin panel that only you (and anyone you invite) can see. Go to yoursite.com/admin/login and sign in with the username and password you were given. Everything described below happens inside this admin panel, reachable from the menu at the top of every admin page.

If you ever forget your password, contact whoever set up your site — passwords can't be recovered automatically for security reasons, but they can be reset for you.

Before your first event: a quick setup pass

You won't need to touch most of this again once it's set, but it's worth doing in order the first time.

  1. Branding. Go to Branding in the admin menu and add your site name, logo, and business/return address (this address shows up on shipping labels if you sell prints). Add your social media links here too if you want them shown on your gallery pages.
  2. Packages and pricing. Go to Packages to set up what you're selling — for example, "5 digital photos for $25" or "1 print + 1 digital photo for $15." You can also sell single prints or single digital downloads without a package; those are configured under Print Options and Download Sizes.
  3. Print labs (only if you sell prints). If you're fulfilling physical prints, add your print lab's name and address under Branding → Print labs. When you mark an order's prints as fulfilled later, you'll pick the lab that handled it, and its address automatically appears as the return address on the customer's shipping confirmation email.
  4. Staff accounts (optional). If someone else helps you run the site — another photographer, an assistant — give them their own login under Users instead of sharing yours. "Staff" can do everything except touch Branding, Print labs, or add other users; "Full admin" can do everything you can.

Setting up your first event

Events are organized in two layers: Folders hold everything from one event, and Galleries are the individual photo sets inside a folder (for example, a folder called "Fall 5K" might hold separate galleries for the start line, finish line, and awards ceremony).

Fastest way to set up a whole event at once: go to Folders → New Folder, type the event name, and in the same form list out the names of every gallery you want inside it (one per line). The site creates the folder and every gallery in one step, ready for you to start uploading into.

Or build it one piece at a time: create the folder first, then go to Galleries → New Gallery and assign each new gallery to that folder as you go.

Uploading photos

Open a gallery and use the upload button — you can select thousands of photos at once. Upload happens in a separate tab, so you're free to keep working while it processes; a progress bar shows you what's done, what failed, and what got skipped.

A few things happen automatically the moment photos land:

  • Bib numbers are read automatically. If your site has this turned on, every photo is scanned for a visible bib number and tagged with it — this is what powers customer search. It's worth a quick glance through a new gallery afterward, since a blurry or angled bib can occasionally get misread; you can fix any tag by hand right on the photo's thumbnail.
  • A watermark is applied to preview images (if you've turned watermarking on for that gallery), so customers can browse before buying without giving away full-resolution copies for free.
  • A cover photo is picked automatically at random for the gallery's thumbnail on your Galleries page, unless you check the "Cover photo" box on a specific photo to always use that one.

Adding participant names from a spreadsheet (optional)

If you have a spreadsheet mapping bib/plate numbers to participant names — common if a race's timing company gives you one — you can upload it on any gallery's edit page under "Add names from a CSV." It adds each name as a searchable tag right alongside that bib number, so customers can find their photos by searching either their bib number or their own name.

It only tags photos that already exist in the gallery at the moment you upload it — anything added afterward won't automatically get a name. To handle that, check "Save this list for reuse on other galleries later this season" when you upload it and give it a label (like the race name). It then shows up in a dropdown, "Or use a saved list," on every gallery's edit page — including the one you're already in — so if more photos come in later, or you just forgot to run it, pick the saved list and click "Apply to this gallery" again. It's safe to reapply anytime: photos already tagged with a name are skipped, so this only catches ones that newly match. Delete a saved list from the same dropdown once you're done with it for the season.

Uploading from your computer (optional desktop app)

For very large batches — thousands of photos from a single race day — there's also a desktop app you can install instead of uploading through the browser. It logs in with the same admin username and password, lets you drag in a whole folder of photos, and uploads them in the background while you keep working on other things.

The main advantage over browser uploading: if your internet connection drops partway through (common at outdoor race venues on spotty wifi), it automatically resumes right where it left off — even if you closed the app or restarted your computer — instead of you having to start the batch over. It uploads in small chunks and safely skips anything that already made it through, so nothing gets duplicated.

This is entirely optional — uploading through the browser works fine for smaller batches.

Setting it up

  1. Run the installer. Double-click the downloaded file and follow the prompts. It adds a normal desktop and Start Menu shortcut — no technical setup needed.
  2. Open "Icon Media Uploader." The first time it opens, log in with your site's URL (e.g. https://yoursite.com) and your usual admin username and password. Check "Remember me" so you don't have to log in every time.

Using it

  1. Pick a gallery. Click into the Gallery field and start typing — it filters the list live as you type, so you don't have to scroll through every gallery on the site to find the one you want. Use the ↻ Refresh button if you just created a gallery on the website and don't see it yet, or the "+ New gallery" link to create one without leaving the app.
  2. Pick a folder within the gallery (optional). If the gallery has sub-folders set up (like "Start Line" or "Finish Line"), choose one here — or leave it as "unsorted."
  3. Choose your photos. "Choose a folder…" grabs every photo inside a folder on your computer at once; "Or choose individual files…" lets you hand-pick specific ones.
  4. Hit Start upload. A progress bar tracks batches as they go. You're free to minimize the app or keep working — it uploads in the background.
  5. If it gets interrupted — wifi drops, laptop sleeps, you close the app — just reopen it later. A banner offers to Resume exactly where it left off.

Keep "Skip" selected for duplicate handling (it's the default) — that's what makes resuming completely safe without creating duplicate photos.

How customers find and buy their photos

This is the part that runs itself once photos are uploaded:

  1. A customer visits your Galleries page (or a direct link you share), finds the right event, and opens the gallery or folder.
  2. They search their bib number — or several at once, separated by commas, handy for a family or team all searching together — or upload a selfie if you have face search turned on.
  3. Matching photos appear. They add the ones they want to their cart, choosing a package, print, or digital download.
  4. Checkout is handled securely through Stripe. Once payment goes through, they're immediately shown their download links and, if they bought prints, a note that prints are on the way.
  5. They also get those same download links by email automatically, plus a link they can use anytime later to check on their print order's shipping status — no need to email you and wait for a reply.

If a customer searches for their bib number and comes up empty (maybe their photos haven't been uploaded yet), they can leave their email and bib number for a "notify me" alert — the site emails them automatically the moment a matching photo is uploaded, even days later.

If a customer loses their download email entirely, point them to yoursite.com/resend — they enter their email, and the site automatically re-sends the download links from their most recent order. You never have to manually dig one up.

For free-download galleries (like a "backdoor" link you hand off to a race director), the first person to grab the whole gallery as one ZIP will see a simple progress page while it's built — for a few hundred large photos this can take several minutes, and it's completely safe to leave that tab open in the background or come back to the same link later. Once it's built once, that exact download becomes instant for anyone else who uses the same link.

Checking in on orders

Go to Orders to see every sale, most recent first. Unfulfilled print orders are highlighted in red so they're impossible to miss. From an order card you can:

  • Mark prints as fulfilled — enter tracking info, pick which print lab handled it, and the customer automatically gets a shipping confirmation email.
  • Resend the confirmation email — useful if a customer says it never arrived.
  • Download any photo directly — no need to place a test order to grab a copy for yourself.
  • Export contact info — download every customer's name/email/phone as a spreadsheet, handy for a mailing list or follow-up.

The Orders and Messages links in the admin menu show a small red number badge whenever there's something new you haven't looked at yet — an easy way to tell at a glance if anything needs attention.

Your Races & Events page

The public page that lists all your events (folders and any standalone galleries) can be sorted three ways: newest first, oldest first, or manually arranged exactly how you want by dragging entries into order — useful for pinning an upcoming race to the top regardless of when it was created.

Cleaning up old events (optional, off by default)

If you want to stop paying for storage on events from a year ago, the Auto-Delete page lets you schedule a folder or gallery for automatic deletion on a specific future date. You'll get a warning email a set number of days beforehand so you have a chance to change your mind, and nothing gets deleted unless you've explicitly turned this feature on — it does nothing at all by default.

A day-to-day cheat sheet

For a typical race weekend, this is roughly the order things happen in:

  1. Before the event: create the folder and galleries (or do it same-day, right before uploading).
  2. During/after the event: upload photos as they come in — no need to wait until you have everything.
  3. Share the gallery or folder link with the race director, on social media, or however you reach participants.
  4. Check Orders occasionally over the following days/weeks for print orders that need fulfilling.
  5. Mark prints fulfilled as they ship.
  6. Move on to the next event — nothing needs to be "closed out" or archived unless you want to.

Getting help

If something looks broken, a customer reports a problem, or you just want to add a feature that isn't here yet, reach out to whoever set up your site for you.
